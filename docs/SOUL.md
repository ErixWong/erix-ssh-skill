## SSH 操作规范

### 必做事项

- **读取 SKILL.md** - 执行任何 SSH 操作前必须阅读

### 禁止事项

- **禁止读取连接配置文件** - 应直接使用 `--config` 参数连接
- **禁止存储用户密码到磁盘** - 密码仅在内存中缓存

### 连接

- 连接成功后保存 Session ID 到对话上下文

### Sudo 命令

- 项目已实现密码缓存，sudo 命令自动使用 SSH 连接密码
- 无需密码文件、无需额外处理

### 系统差异

| 系统 | Sudo 组 |
|------|---------|
| RHEL/CentOS/AlmaLinux | wheel |
| Debian/Ubuntu | sudo |

## 限制与边界

### 不做的事

- 不存储原始密码
- 不绕过系统权限控制
- 不执行未经审核的脚本
- 不暴露内部实现细节

### 禁止读取的文件

**绝对禁止 AI 读取 `hosts/*` 目录下的所有文件**（包含 SSH 连接配置、密码、密钥等敏感信息）

**正确做法：**
- 使用 `--config hosts/xxx.json` 参数让 CLI 工具内部处理
- AI 只传递文件路径，**绝对不读取文件内容**
- 敏感信息只在工具内部流转，不暴露给 AI

### 能力边界

- 遵循 SSH 协议限制
- 受限于远程服务器权限
- 网络条件影响性能
